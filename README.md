# Jumbo Ventures website

Static site for Jumbo Ventures, the leading undergraduate entrepreneurship club at Tufts University.

- `index.html` — home, with the animated Tufts landscape hero (`assets/scene.js`)
- `faq.html` — frequently asked questions
- `network.html` — our network (in progress)
- `assets/styles.css`, `assets/site.js` — shared styles and behaviour

No build step: open `index.html` in a browser, or serve the folder with any static host. Deployed with GitHub Pages from the `main` branch root.

Font: Geist (Google Fonts).
